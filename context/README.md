# Context

Esta carpeta guarda decisiones de producto, UX, seguridad y dominio para guiar el desarrollo de la app.

La app reemplaza un sistema legacy de gestion de tarjetas/creditos usado por empleados. El objetivo principal no es una landing page ni una experiencia de marketing: es una herramienta interna, clara, rapida y confiable para operar todos los dias.

Documentos:

- `atomic.md`: arquitectura de componentes y separacion entre UI generica y features.
- `codex.md`: reglas especificas para trabajo asistido por Codex.
- `commit.md`: convenciones de commits.
- `documentation.md`: criterio para documentacion tecnica.
- `nomenclatura.md`: convenciones de nombres en base, Prisma y frontend.
- `product.md`: alcance funcional y prioridades.
- `ui-style-guide.md`: direccion visual y criterios de interfaz.
- `security.md`: reglas para proteger informacion sensible.
