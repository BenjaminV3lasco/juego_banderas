# Producto

## Objetivo

Construir una app web privada para gestionar personas, tarjetas internas, acuerdos/deudas, pagos/cobros, comercios y auditoria.

## Usuarios

La app sera usada por empleados administrativos. Debe priorizar:

- Carga rapida de datos.
- Busqueda eficiente.
- Lectura clara de saldos, estados y vencimientos.
- Prevencion de errores operativos.
- Registro de cambios importantes.

## Prioridad inicial

1. Personas/clientes.
2. Tarjetas.
3. Acuerdos/deudas.
4. Pagos/cobros.
5. Auditoria basica.
6. Roles y permisos.

## Principios

- No copiar la interfaz vieja, copiar los flujos utiles.
- Evitar datos duplicados.
- Mantener campos legacy opcionales para una importacion futura.
- No bloquear el lanzamiento inicial por migracion de datos viejos.
